# TRY HACKING ME NOW

> **This is TRY HACKING ME NEW!**

**TRY HACKING ME NOW** is a 2D platform game where the player can literally destroy, inspect, and modify the live game itself through a real Python terminal.

The goal is not to give the player a list of cheats. The goal is to expose the game's runtime and let the player discover what is possible.

## Current status

🧪 **Beta — active development**

The project is being built incrementally. Features are only considered complete when they actually work in the running game.

## Core idea

The game world is made from real runtime objects with properties and relationships that can be inspected and modified. The player can use Python to experiment with the live game state and discover solutions that were not explicitly prescribed by the level designer.

Examples of systems planned for runtime inspection and manipulation include:

- Player movement, physics, health, animation and state
- World geometry, platforms, terrain and interactive objects
- NPCs and enemies
- Camera behaviour
- Environment and weather
- Audio and visual effects
- Missions, objectives, checkpoints and level state
- Runtime-created objects
- User interface elements

The game should react to unusual modifications with humorous anomaly messages rather than simply reverting the player's changes.

## Design direction

- 2D side-scrolling platform gameplay
- Cartoon/stickman presentation
- Simple, readable and polished environments
- Real Python terminal integrated into the game
- Runtime introspection and controlled runtime manipulation
- Multiple possible solutions instead of one prescribed hack
- Persistent progression and save data
- 15 planned levels
- No cyberpunk/neon visual identity
